## Weakness inventory for the next Adversarial-Agent run

1. **License classification is still shallow.** Wikimedia and Archive
   both encode edge cases (multi-licence uploads, superseded PD
   rationales) that our regex-based mappers ignore. Recommend a
   dedicated `LicenseClassifier` benchmark with a hand-labelled 100-
   record fixture.
2. **`procedural_density` uses an English cooking-verb list.** Even
   on `cooking_multi` presets, non-English titles score 0 on this
   axis. Recommend adding a language-conditional verb dictionary or
   an n-gram-based procedural detector.
3. **No dedup metric of quality gain.** We count how many duplicates
   were removed but don't quantify the resulting quality-lift per
   query. Recommend a benchmark row that reports mean-quality delta
   pre/post dedup.
4. **YouTube adapter can never proxy media.** Every downstream
   trainer must re-fetch. Recommend a small `resolvers/` module that
   converts our URLs back into safe fetch instructions rather than
   assuming callers know the constraint.
5. **Common Crawl adapter still doesn't iterate WARCs.** The current
   `search()` is a stub returning `[]`; live yield estimate remains
   speculative.
6. **No cross-day baseline diff tool.** We already emit per-day JSON
   reports; a `python -m specint diff a.json b.json` utility would
   let reviewers see regressions on the PR page.
