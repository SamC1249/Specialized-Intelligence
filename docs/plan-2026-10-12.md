# Adversarial-Agent Plan — 2026-10-12

> Author: `Adversarial-Agent`. Second plan in the series; the first
> (`docs/plan-2026-06-20.md`) was co-authored with the bootstrap PR and
> is now fully implemented. This plan attacks the resulting baseline.

## Where we are

Baseline (`reports/baseline-2026-06-20.json`, 8 fixture records across
4 adapters):

| source        | n | n_license_clean | mean_quality | total_duration_s |
| ------------- | - | --------------- | ------------ | ---------------- |
| wikimedia     | 2 | 2               | 0.622        | 357.4            |
| peertube      | 2 | 2               | 0.572        | 822.0            |
| common_crawl  | 1 | 0               | 0.531        | 270.0            |
| archive_org   | 3 | 2               | 0.358        | 1572.0           |
| __total__     | 8 | 6               | 0.499        | 3021.4           |

The baseline is honest but *tiny*. We have four single-fixture tests, a
single HTML page for Common Crawl, and no real yield estimation. The
hard constraints (no paid, provenance-mandatory, comparison-first,
offline-CI) are met, so from here on every change should either
**raise yield**, **tighten license signal**, or **harden
reproducibility** — ideally all three.

## Hypotheses under test

- **H2 (yield).** Switching Wikimedia from title-search to recursive
  `Category:Cooking` traversal yields ≥10× more license-clean video
  records per query-budget unit than the current `generator=search`
  path, with no license-correctness regression. [Artifact-1]
- **H3 (license signal).** Multi-signal license detection
  (`<meta>` → JSON-LD → `<link>` → `<a>`, head > footer > body, with a
  confidence score) lowers Common Crawl false-positive license hits by
  ≥50% on an adversarial fixture set versus the current
  single-field heuristic. [Artifact-2]
- **H4 (comparability guard).** A CI regression gate — "no source may
  lose more than 5% mean_quality or 10% n_license_clean vs. the
  committed baseline on the fixture bundle" — catches silent quality
  rot caused by extractor edits before it reaches `main`.
- **H5 (procedural density).** A verb-density heuristic over
  `title + description + recipe_steps` using a committed cooking-verb
  lexicon ranks "procedurally dense" cooking clips (whisk / sear /
  deglaze …) above talking-head commentary at AUC ≥ 0.80 on a
  hand-labelled 50-clip fixture. [Artifact-3]
- **H6 (generalisation).** The same harness, parameterised by a
  domain → seed-terms taxonomy, produces defensible baselines for *at
  least one* non-cooking "difficult video" domain (surgery or lab-work)
  from the same four adapters, with ≥ 1 license-clean record per
  domain. If not, we need source diversity, not more scoring.

## Adversarial critiques of the current pipeline

1. **Yield is undefended.** We never estimate upper-bound yield per
   source per day. Without an estimate, "wikimedia > peertube" is a
   fixture artifact, not a claim. Add a `--yield-estimate` subcommand
   that pages through result counts (no media download) and reports an
   expected license-clean records/hour figure per source.
2. **One-fixture adapters.** Each source has exactly one happy-path
   fixture. We have no adversarial fixtures: ND/NC-licensed items that
   must be excluded, malformed JSON-LD, mixed `@type` arrays, PeerTube
   responses with missing `account.host`, Wikimedia audio-only
   `File:*.ogg` items mis-tagged as video. Build an *adversarial*
   fixture bundle and assert exclusion.
3. **No deduplication anywhere.** URL-level dedup across adapters is
   trivial and absent. Content-level dedup needs frames and is out of
   scope for metadata-only, but the record-ID collision test
   (`id = f"{source}:{native_id}"`) must at least assert no
   intra-source collisions.
4. **`extractor_git = "dev"` violates the provenance constraint.**
   AGENTS.md requires "the exact extractor commit hash". Resolve at
   import-time from `git rev-parse --short HEAD`, falling back to a
   build-time baked SHA for packaged installs, with `"dev"` only when
   neither is available **and** a warning emitted.
5. **Mean quality ignores duration.** A 10-minute 0.8-quality tutorial
   is worth more than ten 20-second 0.8-quality clips for a world
   model. Add `quality_hours = sum(duration_s * quality) / 3600`
   alongside `mean_quality`; the baseline comparison currently favours
   short-clip-biased sources.
6. **License enum is coarse.** `OTHER_FREE` conflates WTFPL, BSD-style
   "do whatever," and `License: GFDL` edge cases. Add a free-text
   `license_notes` channel on `Provenance` so we can audit without
   bloating the enum.
7. **CI gaps.**
   - `mypy || true` means type regressions pass CI silently.
   - No `pip-audit` → silent vuln drift (we ship a scraper).
   - No `codespell` → documentation typos accumulate.
   - No link-check on `docs/plan-*.md` and `README.md`.
   - No scheduled live integration run — the `search()` paths are
     effectively dead code and will bitrot.

## Out of scope today

- Downloading media bytes.
- Any adapter requiring paid credentials.
- Audio-track filtering (e.g. music→cooking misclassification). Needs
  signal from media.
- Perceptual-hash / CLIP-embedding dedup (needs frames; keep as
  explicit TODO).
- A "fair-use frames" distribution policy. We note the research
  question in `docs/artifacts/06-fair-use-frames-doctrine.md` but do
  not ship a frame extractor — this is a legal-risk cliff and the next
  adversarial plan must decide whether to approach it.

## Risks the next reviewer should challenge

- **Category tree pollution.** `Category:Cooking` contains lots of
  still images and non-video files. Our traversal must filter by MIME
  before accepting, or H2's yield number is a mirage.
- **SepiaSearch rate limiting.** One global endpoint is a single
  point of failure *and* a single point of throttling. The adapter
  must degrade gracefully to the current instance list.
- **Verb lexicon leaks domain.** A hand-curated cooking verb list
  biases the scorer to our favorite dataset. The AUC test must use
  held-out, non-English, and non-Western-cuisine fixtures.
- **Baseline symlink is fragile.** On Windows and some CI runners,
  symlinks don't exist. Store `reports/baseline-latest.json` as a
  committed file whose content is a copy, not a symlink.
- **CommonCrawl Parquet queries are expensive.** `--fixtures` CI must
  never hit S3. Enforce via `SPECINT_RUN_INTEGRATION != "1"` guard.
- **"Difficult video" taxonomy is premature.** Surgery footage online
  is largely CC-BY-NC in NIH repositories; our hard constraint
  excludes those. We may discover the four-source toolkit simply
  doesn't yield a surgery baseline — that's a *valid* and
  informative H6 falsification.
