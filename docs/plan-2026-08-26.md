# Adversarial-Agent Plan — 2026-08-26

> Written by Adversarial-Agent. `Coding-Agent` should pick the highest-
> leverage items from this file when it next runs.

## State of the world (as of today)

The seed plan (2026-06-20) shipped: canonical `VideoRecord` schema, four
offline source adapters (Wikimedia Commons, Internet Archive, PeerTube,
Common Crawl HTML), a metadata-only quality scorer, a comparison
harness, a CLI, offline unit + e2e tests, GitHub Actions CI on
Python 3.11/3.12, and a first baseline
`reports/baseline-2026-06-20.json`:

```
wikimedia     mean_quality 0.62   n_license_clean 2/2
peertube      mean_quality 0.57   n_license_clean 2/2
common_crawl  mean_quality 0.53   n_license_clean 0/1
archive_org   mean_quality 0.36   n_license_clean 2/3
```

Sixty days later, no PR has beaten this baseline. That silence itself is
an adversarial signal: the current scorer is easy to game (any
`CC0 + 720p + non-empty description` record scores > 0.7) and nothing
in CI actually **defends** the baseline. This plan attacks that.

## Hypothesis under test today

> **H2.** Our declared `mean_quality` is decorative: it correlates
> weakly with downstream world-model utility because the scorer
> ignores procedural density, cross-source duplication, and camera
> stability. If we (a) add a labeled downstream-utility calibration
> set, (b) add cross-source dedup, and (c) surface at least one
> narration-density signal, ranking will change materially on the
> current fixtures — and any of those three signals alone will move
> `mean_quality` by ≥ 0.05 on at least one source.

## Attacks on the current weak spots

Ranked by leverage (highest first). Each item names the *file* to add
or edit, and every item terminates in a comparable benchmark row.

### A. The scorer is untethered from downstream usefulness

- **A1. Utility calibration fixture.** Hand-label the existing 8
  fixture records with a ternary `world_model_utility ∈ {no, maybe,
  yes}` and check the labels into
  `tests/fixtures/utility_labels.json` (schema documented in the
  artifacts note 0002). Justification for each label must live in the
  same JSON so future agents can audit.
- **A2. Calibration test.** Add `tests/test_quality_calibration.py`
  that fails if Spearman(quality_score, utility_label) < 0.4 or if
  top-decile precision for `utility == "yes"` < 0.6 on the fixtures.
  This is the first CI check that **defends the baseline** rather
  than merely re-computing it.
- **A3. Narration-density scorer.** In `quality/metrics.py` add a
  `_score_narration_density` component (weight 0.15, redistributed
  from `text_density → 0.10`) that reads a new optional
  `subtitle_events_per_min` field on `VideoRecord`. Wire it up in each
  adapter (Wikimedia `<track>`, PeerTube `captions` field, Archive.org
  `.srt`/`.vtt` sibling files, JSON-LD `transcript` property).

### B. We are almost certainly counting the same video twice

- **B1. `quality/dedup.py`.** Pure-function cross-source dedup on
  (host, duration bucket, title-shingle SHA-1). See artifact 0004 for
  the full API.
- **B2. Adversarial dedup tests.** `test_planted_duplicate` and
  `test_no_false_positive_on_common_terms` as described in 0004.
- **B3. `n_after_dedup` in `BenchmarkResult`.** Optional field so the
  old baseline JSON still validates. `python -m specint compare`
  gains `--dedup / --no-dedup`.

### C. Common Crawl adapter is a single HTML file, not a scalable source

- **C1. `sources/common_crawl_index.py`.** URL-index-first candidate
  discovery, DuckDB SQL against a fixture Parquet in unit tests.
  Fixture Parquet must be < 128 KB (pre-commit large-file gate is
  512 KB).
- **C2. Host allowlist as data.** Move to
  `data/allowlist_hosts.tsv` with `verified_at` timestamps; CI fails
  if any entry is > 365 days old.

### D. CI does not defend anything today

- **D1. Fixture license audit test.** Every record produced from
  every fixture must have `license != License.UNKNOWN` unless the
  fixture is explicitly named `*_ambiguous_*.json`. This catches
  regressions where an adapter silently starts returning UNKNOWN.
- **D2. Provenance completeness test.** Every parsed record must have
  non-empty `provenance.extractor`, `provenance.query`, and a UTC
  `fetched_at`. Catches adapters that forget the `Provenance` block.
- **D3. Schema regression test.** Snapshot the field set of
  `BenchmarkResult` and fail if a field is silently removed (added is
  fine because the model is `extra="forbid"` on records only, not on
  results). Prevents accidental breakage of downstream tooling that
  reads `reports/*.json`.
- **D4. Codespell in pre-commit.** Cheap and catches embarrassing
  README/plan typos before Reviewer-Agent has to point them out.
- **D5. Stop swallowing mypy failures.** Split the CI step into
  `mypy src --pretty` (non-blocking, informational for now) *and*
  `mypy src/specint/records.py` (blocking — the schema module must
  type-check cleanly because it is imported by everything). Migration
  path to strict mypy across the tree in a future plan.

### E. Multilingual gap

- **E1.** Add a `SourceQuery.language` sweep to the compare harness
  and ship a `docs/queries/multilingual-cooking.tsv` seed file with
  cooking terms in EN, ES, FR, JA, HI, PT-BR, AR. The fixture-mode
  compare should iterate over these and emit a per-language row so we
  can see which sources are English-monoculture. Purely metadata; no
  new adapters needed for the first pass.

## Concrete deliverables for `Coding-Agent`'s next PR

Pick from A → E in order. A PR that ships **only** A1+A2+D1+D2 is
already a real improvement because it adds two adversarial CI defenses
plus the first honest calibration signal. Do not try to ship all of it
in one PR.

Any new benchmark row must be committed to `reports/` and referenced
in the next `plan.md` summary.

## Out of scope today

- Any frame or media download (still URL + metadata only).
- V3C ingestion — noted in artifact 0001 but the data-use agreement
  needs a human, not an agent. Track separately.
- YouTube CC listing via Data API — still gated on the Legal Source
  Allowlist review; not for this cycle.

## Risks the next reviewer should challenge

- **A1 hand-labeling is 8 examples.** Any calibration threshold
  derived from 8 examples is noise. Fine for a smoke test, not for a
  gate. When the labeled set reaches ≥ 200, raise the Spearman gate
  from 0.4 to 0.6.
- **Dedup false-positives are silent.** Prefer conservative
  thresholds; log every dropped duplicate to `reports/dedup-*.json`
  with full provenance so audits can reverse a bad drop.
- **Codespell + ruff can fight over identifier casing.** Add a
  `codespell` config that ignores `src/specint/records.py` if it
  starts arguing with `License.CC_BY_SA` etc.
