# docs/artifacts

Distilled notes on external research + datasets that inform the roadmap.
One markdown file per artifact. Format:

- **Source** — URL, venue/year, license of the artifact itself.
- **Claim we care about** — 1–2 lines.
- **Method summary** — bullet points.
- **What it changes for us** — concrete implications for
  `src/specint/*` or a future PR.
- **Risks / disagreements** — the adversarial take.

If an artifact is copyrighted, we quote *at most* short passages under fair
use; the goal here is to encode the *ideas*, not mirror the paper.
