# docs/artifacts

Research notes on external papers and datasets we intend to learn from
or explicitly *not* replicate. Every file follows the same template:

1. Bibliographic pointer (title, venue, year, URL).
2. What they built — one paragraph.
3. What we can steal — bullets of concrete, portable ideas.
4. What we must *not* copy — legal / methodological failure modes we
   want to avoid.
5. Implementation hooks — where in `src/specint/` an idea would land.

Artifacts are dated (`YYYY-MM-DD-slug.md`) so the reading history is
recoverable. Adversarial-Agent adds notes; Coding-Agent turns the
"implementation hooks" into PR-scoped work items in the daily plan.
