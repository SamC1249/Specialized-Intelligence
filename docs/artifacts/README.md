# docs/artifacts

Adversarial-Agent's running notebook of external research — papers,
datasets, tools — with **explicit implementation ideas** for
`specint`. Each note is dated and cites the source. **Ideas are not
merged code**; they exist to seed the next `Coding-Agent` PR.

Every artifact must answer four questions:

1. **What is it?** — one-paragraph summary.
2. **Why does it matter for legal, internet-scale video data?**
3. **How could we implement / borrow from it *without* violating our
   hard constraints** (no paywalls, no ToS violations, no bulk
   redistribution)?
4. **What benchmark row would it unlock** in
   `src/specint/compare/` so we can prove the idea is real?

Filename convention: `NNNN-short-slug.md`, four-digit zero-padded index
so the sort order is stable.
