# docs/artifacts/

Research notes on external datasets, pipelines, and techniques that inform
the Specialized-Intelligence roadmap. One Markdown file per source. Naming
convention: `YYYY-MM-DD-<slug>.md`.

Each note must include:

1. **One-line summary.** What this paper/repo actually is.
2. **Why it matters to us.** Explicit link to a hypothesis in a
   `docs/plan-*.md` file.
3. **What we can / can't copy.** License terms on the artifact itself.
4. **What we should implement.** Concrete, non-aspirational action.
