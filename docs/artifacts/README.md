# Research artifacts

Reading notes on papers, datasets, and APIs that inform our data-collection
strategy. Every note answers three questions:

1. **What does it claim / offer?**
2. **Can we legally use it under the AGENTS.md hard constraints?**
3. **What idea from it do we adopt into our own code, and where?**

Notes are Markdown, prefixed with the year and a short slug. Add a new note
whenever a paper or upstream API shifts a design decision.
