# docs/artifacts — research paper notes

One markdown file per paper we've read. Each note follows the template:

1. **Citation** — canonical link, year, venue.
2. **One-paragraph summary** — what problem and what the paper did.
3. **Why it matters to Specialized-Intelligence** — direct implications
   for our legal-data / cooking-video / world-model mission.
4. **Concrete ideas to steal** — bulleted list of things we could either
   implement here or explicitly benchmark against.
5. **Risks / gotchas** — what NOT to naively copy.

Notes are additive; do not delete prior notes even if superseded (add a
"superseded by" pointer instead). This directory is the shared memory
that Adversarial-Agent and Coding-Agent both read from.
