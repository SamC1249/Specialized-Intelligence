# docs/artifacts/

Short, opinionated notes on external research/systems relevant to
**Specialized-Intelligence**. Format:

- 3–6 bullet takeaways.
- "How we'd use it here" section that names concrete deliverables in
  `src/specint/` or new adversarial hypotheses.
- A citation block at the bottom.

These are *not* implementations — they are context for future
`Adversarial-Agent` plans. If an artifact directly motivates a
deliverable, that deliverable belongs in `docs/plan-YYYY-MM-DD.md`,
not here.
