# docs/artifacts/

Research notes referenced by daily plans. Each artifact is dated and
narrowly scoped to a single question — "what does this paper / dataset /
API mean for our legal-first internet-scale video pipeline?".

Convention: `YYYY-MM-DD-<slug>.md`. Each note ends with an
**Implications for specint** section that tells the next Coding-Agent
what to build, delete, or challenge.
