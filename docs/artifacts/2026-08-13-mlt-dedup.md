# MLT-Dedup — Efficient Large-Scale Online Video Deduplication via Multi-Level Representations and Spatial-Temporal Matching

- Paper: <https://arxiv.org/abs/2606.12215>
- Venue: arXiv 2026-06 (industrial deployment paper).
- Read on: 2026-08-13 (by `Adversarial-Agent`).

## One-paragraph summary

Production video platforms fight near-duplicate uploads (re-encodes, crops,
speed-changes, watermark overlays). MLT-Dedup proposes a two-tier
representation: **sparse clip-level embeddings** for candidate retrieval
under a limited index budget, and **dense frame-level embeddings** loaded
only for verified candidates. The pairwise verifier ("DiF-SiM") adds a
learned differential-feature module for temporal alignment. Reported result:
91 % reduction in on-platform duplicates at 90 % precision, 5× indexing
capacity vs prior baseline.

## Why we care (Specialized-Intelligence angle)

We are today at **T=0**: metadata-only. But when we start actually storing
frames, near-dup is the dominant waste of storage and training-compute
budget:

1. Wikimedia re-uploads the same recipe demo in multiple resolutions.
2. PeerTube federates the same file across instances.
3. Recipe pages on Common Crawl embed the *same* embedded YouTube ID via
   many host domains.

MLT-Dedup's two-tier design maps naturally onto our future pipeline:

- **Tier 1 (metadata)**: our current `quality/dedup.py` module. Uses only
  `(title, duration_bucket, author)` and does not touch bytes.
- **Tier 2 (frames)**: sparse pHash / DCT hash per clip, index in a BK-tree
  or banded-LSH (see the perceptual-hash note in `2026-08-13-phash-bktree.md`).
- **Tier 3 (learned embeddings)**: MLT-Dedup-style ML-VE, only if the tier-2
  index shows we cannot beat 90 % precision.

## Ideas we can steal today

- **Sparse-then-dense split.** Always cache a coarse fingerprint per record.
  We can approximate this in metadata-only mode with our
  `dedup.metadata_digest`, and later swap in a real pHash without changing
  the harness API.
- **Temporal-consistency pruning.** Once we have per-video timestamps of
  matching frames, drop mid-video false positives — a technique straight
  from Ganguly et al. (NSF/Fast Video Dedup, 2024) and MLT-Dedup Sec. 3.
- **Self-supervised augmentation.** For the eventual matching model, they
  augment unlabeled videos with realistic re-encodes (blur, crop, watermark).
  We can bootstrap augmentations from Wikimedia CC-BY-SA content because
  redistribution is allowed with attribution.
