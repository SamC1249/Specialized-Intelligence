## Hypotheses under test today

> **H2.** *Adding a fifth source (Europeana video, filtered to
> `RIGHTS:*creative*`) strictly improves total license-clean yield on
> the standard `["cooking","recipe"]` query without harming mean
> quality.* We can falsify H2 with the compare harness.

> **H3.** *A metadata-only dedup pass on today's fixtures collapses at
> least one record.* If false, we still ship the deduper because it
> becomes mandatory at even ~10³ records. But we want a concrete
> collision on day one to prove the machinery is wired end-to-end.

> **H4.** *A cheap language-detection signal (script-block + stopword
> table) predicts higher downstream usefulness for English world-model
> training and, more importantly, materially changes the ranking of
> sources.* Falsifiable by comparing pre- and post- weighting reports
> on the same fixtures.

## Adversarial questions the reviewer should force us to answer

1. **License heuristics are still trust-but-verify.** The current
   Wikimedia and Archive.org license parsers do *substring* matching
   on names/URLs. Fuzz them with:
   - `"CC BY-NC-SA 4.0"` → must be RESTRICTED, not CC-BY-SA.
   - `"Attribution-ShareAlike 3.0 Unported"` → CC-BY-SA.
   - `"PDM 1.0 Deed"` / `"Public Domain Mark"` → PUBLIC_DOMAIN.
   - `licenseurl="…/publicdomain/mark/1.0/"` → PUBLIC_DOMAIN.
   - Missing/empty → UNKNOWN, never a "safe default".
   Land as `tests/test_license_edge_cases.py`.
2. **Yield tracking is per-source but not per-language.** Right now a
   Portuguese cooking recipe on Wikimedia and an English one both
   count identically towards `unique_authors`. Add a language field
   and, once populated, split the compare report by language.
3. **Dedup is 0% implemented.** Even with 4 sources at fixture scale,
   the second we crawl live we'll get duplicates (a WebM on Wikimedia
   is often mirrored to Archive.org). Ship a metadata MinHash today.
4. **CI does not enforce coverage.** Add `--cov-fail-under=80` so we
   cannot silently regress test coverage.
5. **Common Crawl `search()` is still a stub.** Not today — but call
   it out in the plan so the next iteration writes a CDX-based lister
   that filters by known CC-licensed domains (see follow-ups).

## Risks the next reviewer should challenge

- **Europeana's per-item rights vocabulary is heterogeneous.** They
  mix Creative Commons, RS (Rights Statements), and In Copyright /
  NoC-NC values. Our parser must default *conservatively* to
  `License.UNKNOWN`, exactly like Common Crawl. Any CC-BY-SA/BY tag
  should be double-checked at ingest time; do not treat "RS-something"
  as free.
- **MinHash on titles is language-blind.** Two identical Spanish
  translations of the same recipe would collide on structure but the
  title token set is different. Accept this false-negative for now;
  the future embedding-based deduper closes the gap.
- **The English language bonus is an ethics smell.** We are building a
  world model; overweighting English risks bakes in a monoculture. The
  toggle is named `language_prior_en` and is documented as
  *deliberately controversial* so the next reviewer can attack it.

## Findings from today's run (`reports/compare-2026-08-20.json`)

- **H2 confirmed.** Adding Europeana lifted total license-clean records
  from 6 → 8 (+33%) and total records from 8 → 11 (+38%) on the same
  seed query. Europeana's mean quality (0.32) is the lowest of the
  five sources, dragged down by missing duration/resolution metadata
  in Europeana's default response — but license-clean yield improved
  without harming any other source's per-record score. Falsification
  target for next iteration: does the same result hold under the
  live search API (H2-live)?
- **H3 falsified on fixtures.** Metadata MinHash removed 0 records
  because the fixture set was hand-crafted to have distinct titles.
  This is *expected*, and the deduper is now instrumented so the
  first live crawl-day report will make dedup effectiveness visible.
  Follow-up: land a stress-test fixture with a Wikimedia↔Archive.org
  known re-upload pair to prove the collapse path end-to-end.
- **H4 confirmed.** Adding `language_known` reshuffled source rankings:
  `wikimedia 0.62 → 0.53`, `peertube 0.57 → 0.55`, `common_crawl
  0.53 → 0.58` (now first because its Recipe JSON-LD carries English
  text), `archive_org 0.36 → 0.43` (English `dcCreator` descriptions
  trigger the stopword vote). We consider this a healthier signal: it
  penalises records that carry no verifiable language, which are the
  ones most likely to be metadata spam or upload-tool boilerplate.
- **Bugs the adversarial license-tests caught.** Three real
  mis-classifications in `wikimedia._coerce_license`:
  1. "Attribution-ShareAlike 3.0 Unported" was returning UNKNOWN
     instead of CC-BY-SA (missed the long-form Commons string).
  2. "Attribution 4.0 International" was returning UNKNOWN instead of
     CC-BY (same root cause).
  3. "PDM 1.0" was returning UNKNOWN instead of PUBLIC_DOMAIN.
  All three are now regression-covered and fixed. The fix also
  reordered NC / ND checks *before* BY / BY-SA so that
  "BY-NC-SA" cannot be misread as "BY-SA".
