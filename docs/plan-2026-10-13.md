# Adversarial-Agent Plan — 2026-10-13

> Previous plan: `docs/plan-2026-06-20.md` (bootstrap). It has been ~4 months
> and no `Coding-Agent` or `Reviewer-Agent` run has shipped since the
> bootstrap. This plan **re-opens the untouched items**, adds a sharper
> attack surface for the Coding-Agent, and ships the research artifacts +
> CI gates that the June plan punted on.

## State of the repo (adversarial read)

What exists:

- 4 offline adapters (`wikimedia`, `archive_org`, `peertube`, `common_crawl`),
  each with 1 happy-path fixture.
- A metadata-only quality score with 5 weighted components.
- A comparison harness + CLI (`python -m specint compare`).
- One baseline report: `reports/baseline-2026-06-20.json`
  (`wikimedia 0.62 > peertube 0.57 > common_crawl 0.53 > archive_org 0.36`).
- CI matrix on 3.11/3.12, pre-commit (ruff, hooks, pytest pre-push).

What is **not** actually true despite looking true:

1. **The CI benchmark is a no-op.** `python -m specint compare --fixtures`
   initialises `by_source[slug] = []` and runs the harness over empty lists.
   The committed baseline was generated some other way (likely via the
   `test_e2e_compare` path) and *nothing in CI compares against it*. A
   regression in `parse()` would produce an all-zero `ci-compare.json` that
   CI happily uploads as green. **Fix in this PR.**
2. **"Provenance is mandatory" is only half-true.** Every record carries
   `provenance.extractor`, but `extractor_git` is hard-coded to `"dev"`.
   The git SHA promised by `AGENTS.md` constraint #2 is never captured.
3. **License classification is one adapter deep.** `_coerce_license` is
   duplicated with subtle differences across `wikimedia.py`, `archive_org.py`,
   `peertube.py`, and `common_crawl.py`. A single mislabel in any adapter
   silently pollutes the "license-clean" count. There is no shared,
   fuzz-tested license parser.
4. **One fixture per adapter.** Each parser has exactly one happy path
   and zero known-bad or edge-case fixtures. We ship a parser we have
   never adversarially tested.
5. **The quality score is cooking-specific.** `has_steps` and the
   recipe-shaped text density make the scorer refuse to generalise to
   surgery/sports/manufacturing videos. `AGENTS.md` explicitly says the
   system *must* generalise. There is no domain-plug-in point today.
6. **No dedup.** The same clip can appear on Commons, Archive.org, and a
   PeerTube mirror and will be counted three times in `total_duration_s`.
7. **No "difficult video" axis in the benchmark.** Mean quality is a
   single scalar; the harness cannot answer "which source gives us the
   most procedural density per license-clean hour?" which is the actual
   business question.
8. **No live-source smoke test** exists, even gated behind an env flag.
   None of the four adapters have *ever* been exercised against a real
   upstream in this repo's history.

## Hypothesis under test today

> **H2.** Most of our forward uncertainty is on the *measurement* side,
> not the *source* side. Before we add a fifth adapter we should
> (a) make the benchmark actually gate CI, (b) add adversarial fixtures
> that would catch a silent `parse()` regression, and (c) factor the
> quality scorer so a surgery or sports task can swap in its own weights
> without forking the harness. Any new source added before (a)–(c) will
> look great on fixtures and lie in production.

## Deliverables shipped by this (Adversarial-Agent) PR

Adversarial PRs are usually planning-only, but the June plan went
unimplemented for months, so this PR ships the *measurement scaffolding*
that was supposed to arrive on day two:

- `scripts/run_fixture_benchmark.py` — runs each registered source's
  `parse()` against its canonical fixture, scores it, and writes
  `reports/compare-fixture-<date>.json`. Deterministic, no network.
- `scripts/check_benchmark_regression.py` — compares a benchmark report
  against `reports/baseline-2026-06-20.json`. Fails CI if any per-source
  `n_records`, `total_duration_s`, or `mean_quality` drifts by more than
  the configured tolerance (default 1e-6 for counts, 1e-3 for means).
- `tests/test_contract.py` — cross-adapter invariants (every parser
  returns a list, every record validates against the schema, provenance
  is non-empty, license is a known `License` member, `media_url` is only
  populated for redistributable licenses).
- `tests/test_check_benchmark_regression.py` — unit tests for the gate.
- `.github/workflows/ci.yml` — add a "fixture benchmark + regression
  gate" job and an "offline import" job that imports every module with
  the network blocked, to prove no adapter does I/O at import time.
- `.github/workflows/nightly-integration.yml` — `workflow_dispatch` and
  nightly `schedule` job that runs the live integration suite only when
  the maintainer has set `SPECINT_RUN_INTEGRATION=1` as a repo variable.
- `.pre-commit-config.yaml` — add `detect-private-key`,
  `mixed-line-ending`, and a `check-ast` hook; add a local hook that
  forbids committing records with `license: UNKNOWN` into fixtures.
- `docs/artifacts/papers.md` — annotated bibliography of the 10 papers
  that most directly shape our design choices (SolarWM, Sekai2, Ego4D
  Goal-Step, Ego2World, YouCook2, EPIC-KITCHENS, V3C2, FED dedup,
  LSH video dedup, ViDupe).
- `docs/artifacts/sources-shortlist.md` — ranked candidate sources with
  a licence-basis argument and a yield estimate for each.
- `docs/artifacts/dedup-strategy.md` — proposed metadata → text-shingle
  → perceptual-hash cascade for cross-source dedup, costed in CPU-hours.
- `docs/artifacts/robustness-attacks.md` — adversarial-fixture catalog
  for the Coding-Agent to implement next.

## Deliverables for the next `Coding-Agent` run

Ranked by leverage, highest first. Each item must emit a `BenchmarkResult`
row or add a test; "informative failure" is acceptable per `AGENTS.md`.

1. **Shared `license.py`** that every adapter calls. Fuzz-tested against
   a corpus of 100+ real license strings scraped from Commons, Archive.org,
   and PeerTube. Add a `License.classify(short_name, url=None) -> License`
   function with explicit precedence rules documented inline.
2. **Capture real `extractor_git` SHA.** Add `specint._git.sha()` that
   reads `GITHUB_SHA` if set, else shells out to `git rev-parse --short HEAD`,
   else returns `"dev"`. Thread it through every `Provenance` instance.
3. **Adversarial fixtures** (one per attack in `docs/artifacts/robustness-attacks.md`).
   Minimum per adapter: (a) missing license, (b) NC/ND license (must map
   to `RESTRICTED`), (c) duration-missing, (d) truncated payload. Each
   adapter's test file gets a parametrised test over the attack suite.
4. **Pluggable quality domain.** Refactor `quality/metrics.py` into a
   `QualityDomain` protocol with weights + components. Ship a
   `CookingDomain` (current behaviour) and a `GenericProceduralDomain`
   (drops `has_steps`, keeps `license_clean`, `duration`, `resolution`,
   `text_density`). Benchmark both on the fixture set.
5. **Openverse adapter** (new source). API: `GET https://api.openverse.org/v1/audio/`
   — note Openverse itself only serves images/audio today, but their
   external-source URL builders enumerate the exact CC-filtered search
   URLs on Vimeo, Europeana, Wikimedia Commons, and Flickr. We can
   mirror their logic for *video* without paying anything or breaking
   ToS. Deliver as `src/specint/sources/openverse_proxy.py` that *only*
   produces landing-URL records (no media download), still useful for
   deduplicating against the direct Commons / PeerTube adapters.
6. **Europeana adapter.** `GET https://api.europeana.eu/record/v2/search.json?type=VIDEO&reusability=open`.
   Requires a free API key — gate it behind `SPECINT_EUROPEANA_KEY` env
   and ship offline fixtures. CC-BY / CC-BY-SA / PDM / CC0 only.
7. **Common Crawl URL-Index adapter.** Replace the HTML-only parser
   with the real pipeline documented in `docs/artifacts/papers.md` §CC:
   query `s3://commoncrawl/cc-index/table/cc-main/warc/` with DuckDB on
   `content_mime_detected = 'text/html'`, pull WARC ranges, extract
   `schema.org/VideoObject` and `Recipe.video`. Ship a Parquet fixture
   (<64 kB) so the test stays offline.
8. **Dedup v0.** Implement `specint.dedup.by_signature(records)` that
   collapses records sharing any of: canonical URL, title-shingle
   MinHash signature (datasketch), or declared `media_url` host+basename.
   Dedup must run inside the comparison harness before aggregation and
   be reported as a separate `n_dedup_dropped` column on `BenchmarkResult`.
9. **Multilingual seed terms.** Load `docs/artifacts/seed_terms.yaml`
   with English/Spanish/French/Japanese/Hindi cooking terms. Default
   `SourceQuery` becomes the union; each adapter already supports
   free-form terms so this is purely a config change.
10. **Reviewer-Agent bootstrap.** A `tools/review_pr.py` that, given a
    diff, enumerates: (a) new sources without a benchmark row,
    (b) license strings not covered by the shared classifier, and
    (c) records written to fixtures with `license: UNKNOWN`. CI runs it
    in advisory (non-blocking) mode.

## Out of scope today

- Downloading any actual video. We are URL + metadata only until the
  dedup cascade (deliverable 8) exists.
- YouTube Data API adapter. Allowed by `AGENTS.md` for CC-licensed
  listings, but every integration we have seen in the wild hits the
  10,000 QPD quota in under an hour on cooking terms. Defer until we
  have a cost model.
- Any paid API, any scraping behind auth, any dataset torrent.

## Risks for the Reviewer-Agent (future) to challenge

- **Baseline freeze.** The regression gate pins us to the June baseline.
  If a legitimate adapter improvement raises `mean_quality`, CI will
  fail. The gate must support an opt-in "accept new baseline" step
  (`scripts/check_benchmark_regression.py --update-baseline`) that
  rewrites the baseline file inside a PR.
- **Fixture overfitting.** Every parser is now scored on one fixture
  that the author chose. Adversarial fixtures (deliverable 3) partly
  mitigate this, but we should also sample a random real page per
  adapter under the nightly-integration workflow and diff its parsed
  shape against the committed fixture.
- **Legal drift.** Common Crawl, PeerTube instances, and Wikimedia
  Commons individual uploads can change licence after we cached them.
  We need a `recrawl --revalidate-licenses` loop; file it as a
  deliverable in the next Adversarial-Agent plan.
- **Script hygiene.** Shipping Python under `scripts/` without a
  package means tests have to adjust `sys.path`. The regression test
  does this via a `conftest` fixture; keep it that way or move to a
  real `specint.tools` subpackage.
