# Adversarial-Agent Plan — 2026-08-23

Second plan since bootstrap (2026-06-20). Two months of "nothing shipped"
between plans is itself a signal: `Coding-Agent` has a large baseline
to defend, and the world has moved. New research and law read since the
last plan is captured in `docs/artifacts/` and cited inline below.

## What the world did while we slept

1. **HD-EPIC / Ego2World (May 2026, arXiv 2605.13335)** compiled
   egocentric cooking annotations into an *executable* graph-transition
   benchmark for world models. Confirms cooking as *the* canonical
   world-model vertical, but the underlying HD-EPIC is CC-BY-NC-4.0 —
   redistribution-forbidden. Our gap: a redistributable equivalent.
   See `docs/artifacts/2026-ego2world.md`.
2. **DenseStep2M (2026, arXiv 2604.26565)** — training-free VLM pipeline
   turned HowTo100M into 2 M timestamped procedural steps; 59.1 % of the
   corpus is "Food and Entertaining". Bottleneck is no longer
   annotation, it is **legally-clean raw video**. See
   `docs/artifacts/2026-densestep2m.md`.
3. **MLT-Dedup (KDD 2026)** and NVIDIA NeMo Curator — multi-level
   perceptual + semantic dedup is now a standard middle-stage. Our
   pipeline still has *zero* dedup. See `docs/artifacts/2026-mlt-dedup.md`.
4. **EU AI Act Art. 53(1)(d) transparency template** (adopted
   24 Jul 2025, binding for GPAI models placed on the EU market from
   2 Aug 2025). Requires an itemised, top-domains, license-mix, and
   opt-out-compliance summary. See
   `docs/artifacts/2026-eu-ai-act-transparency.md`.
5. **IETF AIPREF WG + TDMRep + IPTC opt-out best practices v2.0**
   (Mar 2026). Concrete machine-readable opt-out signals now exist in
   the wild; our crawler honours none of them. See
   `docs/artifacts/2026-tdmrep-and-aipref.md`.
6. **SepiaSearch federated PeerTube API** — same JSON schema as our
   existing PeerTube adapter, keyless, ~800-instance coverage.
   See `docs/artifacts/2026-peertube-sepiasearch.md`.

## Hypothesis under test

> **H2 (this cycle).** A pipeline that (a) honours the current stack of
> machine-readable AI opt-out signals **before** every network fetch,
> (b) deduplicates records across sources on cheap metadata signals,
> (c) exports an EU-AI-Act-Art-53(1)(d)-shaped transparency summary,
> **Pareto-dominates** the 2026-06-20 baseline on the tuple
> *(legal-defensibility × unique-yield × transparency-of-provenance)*
> without regressing `mean_quality` per source by more than 0.05.

Falsifiable predictions:

1. Adding SepiaSearch will grow apparent PeerTube yield by ≥3× on the
   `cooking|recipe` query but *unique* yield by less than 2× (federation
   introduces duplicates). Measured via the new `n_intra_source_dup` /
   `n_cross_source_dup` columns.
2. TDMRep + robots.txt AI-preference checks will *reduce* Common
   Crawl-derived yield by 10–40 % on real-world recipe hosts. If
   reduction is <5 % the sample is too small or the parser is broken.
3. The transparency exporter, run over fixtures, must attribute
   ≥90 % of records to a *specific* license class (not `UNKNOWN`);
   otherwise our license-classification heuristics are the true bug.

## Concrete deliverables for `Coding-Agent` (ordered by leverage)

Each item below is scoped so a single PR is feasible, tests are
offline, and each PR must attach a fresh `reports/compare-*.json`
demonstrating measured impact.

### D1 — Opt-out policy layer (LEGAL BLOCKER before any new crawler)

- New module `src/specint/policy/optout.py` with pure functions:
  - `parse_tdmrep_headers(headers) -> Reservation`
  - `parse_tdmrep_json(text) -> list[Reservation]`
  - `parse_robots_ai_directives(robots_txt, user_agent) -> AiPreference`
- New wrapper `src/specint/policy/polite_fetcher.py` that memoises
  per-host `robots.txt` and `/.well-known/tdmrep.json` decisions and
  refuses requests to hosts that reserve TDM rights.
- Extend `VideoRecord` with `tdm_reservation`, `tdm_policy_url`,
  `ai_preference` (Optional). Update `db_structured.md` in the same
  PR — schema is single-source-of-truth.
- Tests: `tests/fixtures/policy/` with mixed robots.txt, `tdmrep.json`,
  meta-tags, and headers. Parser must be deterministic and cover
  every branch.

### D2 — SepiaSearch federated PeerTube adapter

- `src/specint/sources/sepiasearch.py` (subclass of `PeerTubeSource`,
  base URL swap).
- Fixture `tests/fixtures/sepiasearch/search_cooking.json`.
- Register slug `peertube_federated` in `sources/__init__.py`.
- Must not ship without D3 (dedup) also merged, else yield metrics
  become misleading.

### D3 — Metadata-only cross-source dedup

- MinHash over token-shingles of `title + description[:500]`, plus
  URL canonicalisation (strip UTM, trailing slash, lowercase host).
- New columns on `BenchmarkResult`: `n_intra_source_dup`,
  `n_cross_source_dup`, `unique_after_dedup`.
- New field on `VideoRecord`: `duplicate_of: str | None` (canonical
  record id). Never delete duplicates — preserve provenance chains.
- Fixture test that seeds one obvious cross-source duplicate
  (Wikimedia video also indexed on Internet Archive) and asserts
  the clustering finds it.

### D4 — EU-AI-Act transparency exporter

- `src/specint/compare/transparency.py` with a `TransparencyReport`
  Pydantic model matching the Commission's template sections
  (metadata, data-source categories, governance).
- CLI: `python -m specint transparency --input reports/*.json --output docs/transparency-YYYY-MM.json`.
- CI job: round-trip fixtures through this exporter and validate the
  output JSON against the model schema.

### D5 — Cascade-shaped quality scorer

- Refactor `src/specint/quality/metrics.py` from a flat weighted sum
  into a two-stage cascade: (i) legal gate, (ii) weighted metadata
  score computed only if legal gate passes.
- Add `steps_per_minute` and `has_transcript` sub-scores from the
  DenseStep2M reading.
- Backwards-compat: `score_record` still returns a float in [0,1];
  add `score_record_explained(record) -> dict[str, float]` for
  debuggability. All existing tests must still pass.

### D6 — Multilingual query rotation

- Seed term dictionary in `src/specint/queries/cooking.yaml` covering
  English, Spanish, French, Japanese, Hindi, Mandarin. Rotate through
  during a single crawl and dedup by translation later.
- Explicit non-goal for this PR: quality scoring across languages —
  our English-only text-density heuristic will look worse for CJK
  scripts. Documented failure mode.

## CI / test-discipline improvements shipping *today* with this plan

These are `Adversarial-Agent`'s prerogative (attack existing weaknesses
in test discipline, not new features):

1. **License-invariant test on fixtures** — every checked-in fixture
   must obey "if `media_url` is set, then `license.is_redistributable`".
2. **Provenance-invariant test** — every record emitted by any
   adapter's `parse()` must carry non-empty extractor and non-null
   fetched_at; `id` must be stable across two calls to `parse()` on
   the same input.
3. **Baseline regression test** — read
   `reports/baseline-2026-06-20.json`, rerun the fixture harness in
   the test, assert per-source `mean_quality` is within [baseline - 0.05,
   baseline + 0.30]. This locks in the "comparison-first" rule from
   `AGENTS.md`.
4. **Fixture JSON validity** — every fixture under `tests/fixtures/`
   must be valid JSON (or valid HTML for Common Crawl). Cheap to
   assert, prevents silent fixture corruption.
5. **Registry-completeness** — every `BaseSource` subclass that ships
   with a fixture directory must be registered in
   `src/specint/sources/__init__.py::REGISTRY`.
6. **New pre-commit hook** — run the license-invariant + fixture
   JSON validity checks on `pre-commit` (fast) in addition to the
   existing `pre-push` pytest.
7. **CI**: add a `transparency-lint` no-op job today that will be
   fleshed out under D4; keeps the workflow YAML wire in place.

## Out of scope today

- Actual VLM-driven annotation (D-tier for a later plan).
- Any adapter that requires an API key at run time.
- Distributed crawling infra — still single-process.

## Risks the next reviewer should challenge

1. **License-classification precision.** Our heuristics still return
   `License.UNKNOWN` for a large tail. Predicted transparency-summary
   `unknown` rate must be <10 %; if it is higher, the fault is here,
   not upstream.
2. **Domain concentration.** If dedup + top-domains reveals that
   >50 % of records collapse to <5 domains, our "internet-scale"
   framing is false and we must go multilingual (D6) sooner.
3. **English-only quality proxy.** `_score_text_density` counts
   characters; CJK scripts get artificially low text-density scores.
   Multilingual normalisation is a required follow-up to D6.
4. **Perceptual dedup on thumbnails is fragile.** Wikimedia auto-
   generates thumbnails with watermarks; Internet Archive resizes
   aggressively. A metadata-only MinHash is the safe first step.
5. **AIPREF is still an I-D.** Its wire format may shift before RFC.
   Parser must tolerate schema drift; keep the enum permissive.
