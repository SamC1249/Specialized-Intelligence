## Context (what shipped since 2026-06-20)

The seed PR gave us four offline adapters (Wikimedia, Internet Archive,
PeerTube, Common Crawl), a metadata-only quality scorer, and a
single-query comparison harness. The baseline in
`reports/baseline-2026-06-20.json` ranks:

    wikimedia (0.62) > peertube (0.57) > common_crawl (0.53) > archive_org (0.36)

Total mean quality across sources: **0.499** on 8 records, 6 license-clean.

## Where the seed is weakest — attack surface

1. **Single-query benchmarks lie.** One `SourceQuery` cannot decide
   whether wikimedia genuinely dominates archive_org — the mean is
   sensitive to which fixtures we happened to pick. **We need a
   `SourceQuerySuite` (query × source matrix) so per-source signal
   averages over N queries.**
2. **The scorer is monotone but coarse.** `has_steps` is binary; a
   Wikimedia video with rich English procedural narration in the
   *description* gets no credit for procedural density. Meanwhile a
   noisy non-English archive_org upload is not language-penalized at
   all. **Hypothesis: a v2 scorer with (procedural-verb density,
   English-signal, longer-text bonus) will re-rank without regressing
   license-cleanliness.**
3. **Cross-source duplicates are invisible.** A CC-BY-SA cooking clip
   uploaded to *both* Wikimedia Commons and Internet Archive currently
   counts twice — inflating yield and quality. **We need a dedup step
   in the harness, keyed on canonical URL + normalized title, and a
   `n_duplicates` field on `BenchmarkResult` so we can *see* the
   overlap between sources.**
4. **Common Crawl is stuck at UNKNOWN license.** The seed parser never
   inspects `<link rel="license">` or `<meta name="license">` on the
   host page. Many food-blog CMSes emit exactly those tags. **Lifting
   Common Crawl into CC-BY where evidence exists should measurably
   raise its `n_license_clean`.**
5. **Reports aren't comparable across days.** Two `reports/*.json`
   files can't be diffed without eyeballing. **Ship a
   `python -m specint diff` that emits per-source delta rows so we can
   answer "did we get better?" mechanically.**
6. **No integration harness.** We never even *try* live calls; if the
   MediaWiki API silently changes shape tomorrow, we won't notice
   until a human runs it. **Add env-gated integration tests that skip
   in normal CI but run when `SPECINT_RUN_INTEGRATION=1`.**
7. **CI is lax.** `mypy` runs with `|| true`; there is no coverage
   floor; ruff format-check is only advisory. **Tighten CI: strict
   mypy on `records.py` and `quality/`, require ≥90% coverage on
   `src/specint/`, fail on formatting drift.**

## Hypotheses under test today

- **H1 (multi-query stability).** Running each source against ≥3
  disjoint queries reduces per-source rank volatility vs a single
  query. Measure: variance of `mean_quality` per source across
  `SourceQuerySuite` runs.
- **H2 (scorer v2 beats v1).** v2 = v1 + procedural-verb density +
  English signal + longer text-density curve. Prediction: on the same
  fixtures, `mean_quality(v2, __total__) ≥ mean_quality(v1,
  __total__)` **without** dropping `n_license_clean`. If it drops
  either, we roll back.
- **H3 (dedup surfaces overlap).** ≥1 duplicate across
  wikimedia/archive_org fixtures will be exposed once we add title
  normalization and native-id dedup. Even zero duplicates is
  informative — it tells us the four sources have near-orthogonal
  catalogs, which is good news for corpus construction.
- **H4 (CC license lift).** Adding `<link rel="license">` parsing
  makes ≥1 Common Crawl fixture record redistributable, moving
  `common_crawl.n_license_clean` from 0 to ≥1 on the enriched
  fixture.

## Risks the next reviewer should challenge

- Scorer v2 could quietly encode English bias into "quality". We
  mitigate by keeping the English-signal weight modest (≤0.10) and by
  keeping v1 available for non-English cohorts.
- Title normalization for dedup can over-merge distinct dishes
  ("Pasta" vs "Pasta with Garlic"). We use Jaccard on shingled tokens
  with a conservative threshold and log dropped pairs to the report.
- Common Crawl license inference from meta tags can be forged by
  hostile pages. We only *upgrade* to CC-BY when both a
  `creativecommons.org` URL **and** a `rel="license"` attribute
  agree; otherwise stay UNKNOWN.
