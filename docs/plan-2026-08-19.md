## What shipped

- **Cross-source dedup** (`specint.quality.dedup`): canonical URL keying
  (Commons thumb prefixes, Archive.org `download/`↔`details/`) plus
  title-shingle Jaccard `>= 0.85` gated by author/duration. Union-find
  cluster with license-preferring representative selection. Fully
  deterministic on fixtures.
- **Procedural-density scorer** (`specint.quality.procedural`):
  metadata-only imperative-verb + unit-of-measure + numeric-quantity
  density, EN/ES/FR/DE/IT lexicons. Exposed as a `v2_procedural`
  scorer profile that is **additive-boost only** (`v2 >= v1` for every
  record) so it can never Pareto-regress the baseline.
- **Stoplist language detector** (`specint.quality.langdetect`) for
  {en, es, fr, de, it, pt, ja} — backfills `record.language` inside
  the harness so `languages_seen` isn't an artefact of upstream
  tagging quality.
- **Multilingual cooking search terms** (`specint.search_terms`) with
  a `expand_query` helper.
- **Wikidata SPARQL source adapter** — new, fixture-driven; uses
  `wdt:P10` (video) and `wdt:P275` (license Q-entity) with an offline
  QID→License map.
- **`BenchmarkResult` schema extended** with
  `n_unique_after_dedup`, `license_clean_ratio`,
  `mean_procedural_density`, `languages_seen`, `scorer_profile` (see
  `db_structured.md`).
- **New CLI subcommands**: `specint bench` (Pareto-compares scorer
  profiles on fixtures; exit code 3 on Pareto-regression, 4 on mixed)
  and `specint dedup-report`.
- **Ranking module** (`specint.compare.ranking.compare_runs`) —
  deterministic Pareto verdict between two harness runs.
- **CI**: new bench + dedup steps that block on Pareto-regressions;
  artifact upload extended.

## Open questions for the next Adversarial-Agent

1. Wikidata fixture is anecdotal. What's a defensible offline
   yield estimator for SPARQL (row cap × distinct-license ratio) so
   `bench` can meaningfully rank Wikidata against Commons?
2. Should `v2_procedural` also detect the *inverse* — high-verb but
   zero-quantity clips (chatty vlogs pretending to be recipes)? Add a
   `chattiness` penalty?
3. Dedup currently trusts declared duration. For adversarial
   re-uploads with 5–15% time-stretch, we need audio-fingerprint-lite
   (e.g. compressed histogram of caption timestamps).
4. Language detector is stoplist-only. Add romanization for `ja` or
   swap to a compact n-gram model shipped as a data file?
