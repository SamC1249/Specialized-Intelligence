## Hypotheses under attack today

- **H1 — Scalar quality is lossy.** A single `quality_score` can not
  express "kept but risky" vs "kept and gold". SolarWM (arXiv:2609.02886)
  shipped a three-tier scheme (`xhigh`/`high`/`rejected`) that keeps
  every rejected record with an explicit `failure_reasons` list so
  filters are reversible. Predicted win: at a fixed selection budget,
  tier-aware sampling improves procedural coverage vs top-K on the
  scalar.
  Test: `python -m specint compare --tier xhigh --fixtures` beats
  scalar top-K on `n_license_clean / total`.

- **H2 — URL-only dedup is fictional.** The same "bread rising"
  timelapse is likely mirrored across Commons and Archive.org.
  Cross-source collisions collapse silently into "unique yield" today,
  polluting downstream sampling and inflating our reported per-source
  win. Predicted: adding a Jaccard≥0.85 title-shingle rule + normalised
  URL rule finds at least 1 collision in an 8-record fixture set that
  intentionally mirrors one Commons↔Archive item.

- **H3 — Common Crawl parser is one-shape brittle.** Our single fixture
  is a schema.org `Recipe` with an embedded `video`. Real Common Crawl
  is a menagerie: `VideoObject` at the top level, `hasPart→Clip` nested
  structures, `embedUrl`-only records, license carried on the parent
  `CreativeWork`, and outright missing licences. Predicted: with 4
  additional adversarial fixtures the current parser will (a) crash on
  the `hasPart` shape, (b) misclassify the missing-licence page as
  `UNKNOWN`-but-emit-a-`media_url`, and (c) silently drop the
  embed-only record.

- **H4 — Cooking is a special case pretending to be universal.**
  `SourceQuery` has no notion of a *domain*. The mission (AGENTS.md)
  requires generalisation to surgery/lab/manufacturing/sports. Baselining
  those domains today (against the *same* four adapters) will show that
  wikimedia dominates cooking but is *thin* on surgery/manufacturing —
  attacking our own home turf reveals which adapter to prioritise next.

- **H5 — Invariants stated in prose are invariants that will drift.**
  AGENTS.md rule #1 ("no `media_url` for non-redistributable") is a code
  invariant, not a comment. It should be a property test that fuzzes
  every parser with random payloads and asserts the invariant on all
  outputs. Predicted: at least one parser silently violates the
  invariant on a hand-crafted edge case; property tests either prove
  or falsify this.

- **H6 — Without a regression gate, quality decays under refactor.**
  Any change to `WEIGHTS` in `metrics.py` shifts baseline scores.
  Without a CI gate, a well-intentioned refactor can quietly regress
  `mean_quality` by 20% and nobody sees it. Predicted: a strict
  regression check on `reports/baseline-2026-06-20.json` (fail if any
  source `mean_quality` drops > 1%) will catch a class of bugs that
  today's tests do not.

## Risks the next reviewer should challenge

- **Title-shingle Jaccard is language-dependent.** Threshold 0.85 was
  chosen with English in mind. Multilingual roll-out (memory notes
  this as an open item) may need per-language thresholds; the current
  plan does not.
- **`extractor_git` from `git rev-parse HEAD` is a runtime dependency
  on a `.git/` directory.** Fine locally, wrong in a Docker sdist. The
  fallback to `"dev"` must be tested with `GIT_DIR` unset.
- **Regression gate at > 1% is arbitrary.** SolarWM uses "kept vs
  promotion" rules, not percentages. We should track *tier
  distribution* changes as the regression signal once P2 lands.
