# Adversarial-Agent Plan — 2026-07-11

## Where the baseline is fragile

Baseline (`reports/baseline-2026-06-20.json`) ranks:
`wikimedia 0.62 > peertube 0.57 > common_crawl 0.53 > archive_org 0.36`.
That ordering is deceptive on three axes:

1. **`archive_org` is penalised for structural reasons, not content.** It
   never exposes `width`/`height`, so the resolution component is
   always zero — even for known 720p+ items. The scorer punishes
   metadata gaps as if they were content quality.
2. **`common_crawl` is inflated.** JSON-LD self-reports `width`, `height`,
   and `duration`, which we accept at face value. The Adversarial risk
   from 2026-06-20 was explicit here: recipe sites lie about
   `contentUrl`, and by extension the whole VideoObject block.
3. **License-clean count is not the same as usable hours.** An 18-minute
   PD Prelinger clip and a 40-second CC0 GIF are weighted identically
   in `mean_quality`. Yield-weighted metrics are missing.

## Hypotheses under test today

- **H2.** A scorer that (a) treats *missing* metadata as neutral (~0.5)
  rather than zero, (b) tiers licenses by attribution burden
  (CC0 > PD > CC-BY > CC-BY-SA > OTHER_FREE), and (c) rewards
  procedural-verb density in title+description+steps will re-rank the
  four sources without changing any fixture bytes — and will move
  `archive_org` up because its Prelinger PD clip is genuinely useful.
- **H3.** Cross-source dedup by (canonical URL, media URL, and shingled
  title) collapses ≥1 pair on realistic mixed fixtures. If it collapses
  zero pairs, our sources are strictly disjoint and we should design
  future sources to overlap intentionally (for redundancy).
- **H4.** Adding *YouTube CC-only* as a metadata-only adapter meaningfully
  raises yield (records/day) at zero cost to license-cleanliness,
  because we filter on `videoLicense=creativeCommon` server-side.
- **H5.** Multilingual seed terms (es/fr/de/ja for cooking) unlock
  non-English content on Commons and PeerTube without any code changes
  to the adapters themselves — provided `SourceQuery` carries a
  languages list and adapters propagate it.

## Success criteria (falsifiable)

- **Q1.** v2 scorer changes at least one source's rank on the
  2026-06-20 fixtures. Either it improves things, or we document why the
  change was still informative (per AGENTS.md comparison rule).
- **Q2.** Cross-source dedup runs on a mixed record set in <5 ms per
  record on modest fixtures.
- **Q3.** YouTube adapter refuses to emit media URLs; every emitted
  record must have license ∈ {CC-BY} or `RESTRICTED`.
- **Q4.** Multilingual query returns non-English titles from a
  fixture that only contains non-English records for the target
  language.
- **Q5.** All previous tests still pass. CI matrix stays green on 3.11,
  3.12, 3.13.

## Risks the next reviewer should challenge

- Scorer v2 introduces a *neutral* value for missing metadata, which
  could paper over real quality gaps. Mitigation: report v1 and v2
  side-by-side forever; do not delete v1.
- YouTube's `videoLicense=creativeCommon` filter is upstream — if
  Google mislabels, we mislabel. Mitigation: never expose `media_url`
  from YouTube regardless of license (URL + provenance only).
- Multilingual seed-term expansion may accidentally match unrelated
  terms across languages ("recette" in French, "recipe" in English).
  Mitigation: keep expansion in one editable file and score it against
  a language-tagged fixture before enabling in production.
